# 小黑盒内容读取

**让你的 AI 机器人看懂小黑盒帖子，和你聊正文、配图及评论区。**

把帖子链接或分享卡片发给机器人，它就能结合实际读到的内容总结重点、解释配图、讨论网友的观点。

<img src="logo.png" width="120" alt="小黑盒内容读取插件图标">

## 能做什么

- **读帖子**：读取标题与正文，整理游戏资讯、攻略和讨论内容。
- **看配图**：下载帖子中可取得的图片，交给支持视觉的聊天模型。
- **聊评论**：读取接口返回的部分评论和楼中楼，帮助机器人了解讨论。
- **找内容**：按游戏或主题关键词，从匹配分区查找帖子；没有匹配分区时筛选推荐内容。
- **接着聊**：分享后继续追问，或者引用旧卡片讨论指定帖子。

适用于 **AstrBot 4.29.3 及以上、Python 3.12**。已验证 AstrBot 4.29.3，消息接入为 QQ / OneBot。

## 安装

1. 在 **AstrBot → 插件市场** 搜索「小黑盒内容读取」，点击安装。
2. 等待 AstrBot 安装 Python 依赖，确认插件已启用。
3. 为 AstrBot 配置聊天模型；想让机器人看懂配图，需要选择支持图片输入的模型。
4. 按下面的步骤扫码登录小黑盒。

本插件直接连接小黑盒，所需 Python 依赖由 AstrBot 安装，正常使用时无需额外部署读取服务。

## 扫码登录

打开 **AstrBot → 插件 → 小黑盒内容读取 → 插件视图 → 账号与状态**。

1. 点击 **验证当前登录**。已登录时可以直接使用。
2. 如果尚未登录，点击 **获取登录二维码**。
3. 使用手机上的 **小黑盒 App** 扫码，在手机上确认登录。
4. 再次点击 **验证当前登录**，确认页面显示已登录。

二维码过期时重新获取；提示设备确认或验证码时，先完成平台要求的验证。登录失效后在本页重新扫码。

## 怎么使用

### 私聊读帖子

从小黑盒 App 复制帖子分享链接，发给机器人，然后提问：

> 读一下这篇帖子的正文、配图和评论，大家在讨论什么？

### 群聊读帖子

将帖子链接或分享卡片发到群里，**@机器人** 提问；也可以引用那张卡片再 @机器人：

> @机器人 这篇攻略的关键点是什么？评论区有哪些不同意见？

### 按主题找帖子

> 帮我在小黑盒找一些 Apex 相关的帖子。

当前采用「匹配游戏分区，再读取分区帖子」的方式，找不到分区时筛选推荐内容，覆盖范围和小黑盒 App 的全站搜索会有区别。搜索需要聊天模型支持工具调用，并在当前会话中启用本插件的工具。

### 继续追问

分享后可以继续问「第三张图是什么」「评论里为什么这么说」。指定更早的帖子时，引用对应卡片或重新发送链接即可。最近分享记录按群聊、私聊分别保存，最长保留两小时；找不到原帖时请重新分享。

## 常用设置

在 **插件 → 小黑盒内容读取 → 配置** 中修改：

| 设置 | 用途 | 建议起步值 |
| --- | --- | --- |
| `enabled` | 启用插件 | 开启 |
| `auto_read` | 回复帖子时自动读取内容和配图 | 开启 |
| `heybox_max_images` | 每篇最多下载的配图数量 | 6 张 |
| `heybox_max_comments` | 帖子解析时的评论数量上限 | 24 条 |
| `heybox_cache_seconds` | 帖子详情的缓存时间 | 600 秒 |
| `allowed_platforms` | 限制在哪些机器人实例上使用 | 留空，允许全部实例 |

## 常见问题

**机器人还是只知道标题？**

先在「账号与状态」验证登录，再确认 `auto_read` 已开启。引用原卡片并 @机器人，明确要求读取正文、配图和评论。如果帖子已删除或账号无法访问，插件也无法取得对应内容。

**文字能读，图片看不懂？**

请确认聊天模型支持图片输入，且 `heybox_max_images` 大于 0。直接分享帖子后提问，会尝试将配图交给模型；单独调用读取工具的文字结果不能代替图片识别。

**为什么没读到所有评论或图片？**

读取范围受帖子权限、接口返回和数量限制影响。长帖、懒加载图片、隐藏评论或更深的楼中楼可能无法完整取得。

**插件安装失败怎么办？**

查看 AstrBot 日志中的依赖错误，将错误和本仓库链接交给 Agent，请它在 AstrBot 实际使用的 Python 环境中，按 `requirements.txt` 补装依赖后重新加载插件。

**会增加模型费用吗？**

读取帖子本身不调用语言模型。机器人回答时，正文、评论和配图会增加聊天模型的输入用量，可以通过数量设置控制用量。

## 数据与备份

- 插件数据及登录状态：`data/plugin_data/astrbot_plugin_heybox_reader/`。
- 插件配置：`data/config/astrbot_plugin_heybox_reader_config.json`。

备份时同时保存这两项，登录文件请妥善保管。卸载插件后，已保存的登录文件需要自行处理。
