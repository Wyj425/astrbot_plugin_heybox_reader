# 配置说明

只在插件自己的配置页填写。不要把真实配置提交到 GitHub。

| 设置 | 默认值 | 说明 |
|---|---|---|
| `enabled` | true | 启用平台读取 |
| `auto_read` | true | 在已触发模型回复的消息中自动读取分享链接及配图 |
| `allowed_platforms` | [] | 允许的 AstrBot 消息平台实例ID；空为全部 |
| `cache_seconds` | 600 | 共享搜索和内容缓存秒数（30–1800） |
| `max_images` | 6 | 最多读取的配图数量（0–8） |
| `max_comments` | 24 | 最多读取的可见评论数量（0–36） |
| `heybox_max_images` | 6 | 最多读取的配图数量（0–8） |
| `heybox_max_comments` | 24 | 最多读取的可见评论数量（0–36） |
| `heybox_cache_seconds` | 600 | 共享搜索和内容缓存秒数（30–1800） |
